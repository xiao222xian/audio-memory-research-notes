# 背景、目标与贡献边界

## 从内容生成转向可信性

长时间录音通常同时含有近场对话、环境声、扬声器播放和旁人声音。如果系统仅以“能转录、能概括”为准入条件，就可能把外部媒体的情节写成用户自己的经历。对个人记录产品而言，这比一般措辞不佳更严重：用户需要纠正事实，而且错误可能继续进入长期记忆。

研究目标因此拆成五个问题：内容来自哪里、说话者是谁、证据是否完整、应该采取什么产品动作、最终记录是否真实且值得保留。单个分类器无法替代所有这些判断。

## 研究范围

复盘覆盖四类工作：媒体污染治理、身份归因诊断、无证据生成分析、生成前准入与端到端追踪。长期记忆只作为证据传播的后续研究方向，不把实验性设计写成已经上线的成熟能力。

这不是公开的硬件方案，也不包含商业定位、合作方、部署拓扑、供应商配置、真实用户案例或原始素材。

## 个人工作与团队资产

历史工作记录支持将作者的参与范围概括为：问题拆解与评测口径梳理、控制变量实验与消融、指标分析、错误血缘追踪、人工复核工具及交接说明的整理。公开文章由这些记录重新组织，重点是质量治理的方法和结论。

音频基础链路、生成服务、存储基础设施以及记忆实验属于多人协作的系统背景；本仓库不将整个系统的设计、全部模型能力或所有实现归为个人独立完成。现存归档不足以逐模块确认全部人员的作者身份，也不支持虚构贡献占比或个人负责的商业收益。

## 不同的“完成”

完成一次离线回放，代表该输入及配置下有了结果；具备可运行代码，代表实现存在；通过一次引用检查，代表输出满足某项结构约束。这些状态都不能直接等同于真实用户效果改善、生产部署完成或正式产品验收。
