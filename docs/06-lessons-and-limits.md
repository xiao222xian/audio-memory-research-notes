# 取舍、局限与后续方向

## 本次最有价值的取舍

**拒绝生成是正常输出。** 缺少录音、身份不确定或无法支持一个完整事件时，应允许跳过或等待补证据，不能为了结构完整而要求模型编出叙事。

**不能只优化拦截能力。** 更严格的策略可能减少误归因，也可能系统性遗漏用户参与较少但确实重要的事件。提高安全默认值后，需要专门评估正常内容损失。

**让模型目标与产品标签对齐。** 重放检测、媒体内容判断、整段删除和最终卡片是否值得保留是不同任务。模型在自己的任务上有效，不代表可以直接替代产品决策。

**先用控制变量回答问题，再扩大改动。** 把多个规则、顺序调整和新模型同时加入，难以知道改善来自何处，也容易把偶然收益当作可靠机制。

## 仍未解决的限制

- 固定样本小、多次调试复用，不能代表跨设备、语言、环境的总体效果。
- 复审标签存在模型预测展示造成的偏差；部分最终卡片标签采用继承和复盘。
- 多轮卡片来自重复窗口，观测之间相关，不能简单当作独立试验。
- 正常对照存在代理标签，质量分实验的误拦截比例需要谨慎解释。
- 分组生成实验缺少充分真值，引用合法也不足以证明生成内容真实。
- 声音主体识别与最终叙事归因是两个问题，修复方案没有可据以宣称的线上改善数字。
- 记忆实验不等于生产功能，不推断已经实现长期用户价值。
- 没有公开完整数据、私有实现或提示，聚合指标复核不等于完整可复现研究。

## 如果重新启动研究

1. 收集未参与调试的新场景，独立标注内容来源、动作和时间边界；隔离训练、调试与验收集合。
2. 将混合片段切分作为独立变量，分析短时但强语义媒体如何影响事件主题。
3. 在单事件粒度建立生成/跳过真值，并单列“参与少但行为明确”的内容，测量遗漏。
4. 保留跨层身份不确定性；人工核对生成中的归因陈述，不只测声纹或说话人分类。
5. 在必要授权下开展有限灰度，同时看污染率、正常内容保留率、用户纠错与成本延迟。

以上步骤是后续方向，不是本项目已经完成的验证。
